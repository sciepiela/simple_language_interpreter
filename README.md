Interpreter prostego języka

Celem tego projektu jest utworzenie interpretera mogącego przetwarzać prosty 
język programowania.


Założenia języka:

typy zmiennych: 
var - zmienna numeryczna 
logic - zmienna logiczna (true/false)

instrukcje warunkowe:
if (warunek) {kod}

pętle:
while (warunek) {kod}
